Project Title: Number Guessing CLI App | PostgreSQL & Bash Scripting

Project Description:
Developed an interactive command line interface (CLI) application that dynamically interfaces with a PostgreSQL database. The architectural focus of this project lies in managing the data flow between a Bash script and a relational database, implementing data persistence, and handling input validation, which are core concepts essential for robust backend operations and automated workflows.

Key Technical Skills Applied:
1) Data Architecture (PostgreSQL): Designed a relational database schema to track user profiles and historical session data. Embedded raw SQL queries directly within the shell script to execute real time read and write operations and data retrieval.
2) Scripting & Control Logic (Bash): Built a continuous interactive loop handling standard input and output. Utilized environment variables, conditional operators, and strict while constructs to manage complex execution flows programmatically without relying on graphical interfaces.
Version Control (Git/GitHub): Maintained rigorous code lifecycle management using Git. Structured the commit history semantically to clearly separate the database state configuration (the .sql dump) from the evolution of the application logic (.sh).
